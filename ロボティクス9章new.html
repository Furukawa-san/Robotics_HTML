第9章 詳細解説

第9章を、式の導出から実装手順までつなげて読む

PDFの章全体は、ラグランジュ法で構造を見通し、ニュートン・オイラー法で計算機に載せる、という二段構えです。ここでは「何を求め、どの式が何を表し、Python実装では何に対応するか」を冒頭でまとめます。

9.1

2自由度平面ロボットをラグランジュ法で導く

一般化座標を θ1, θ2 とし、各リンクの重心位置、速度、運動エネルギー、位置エネルギーを順に計算します。最後にラグランジュ方程式へ代入し、関節トルク τ1, τ2 を得ます。

9.2

M, h, g の性質を一般形で理解する

運動エネルギーを 1/2 qdot^T M(q) qdot と書くことで、慣性行列 M(q)、遠心力・コリオリ力項 h(q,qdot)、重力項 g(q) の役割が明確になります。

9.3-9.7

ニュートン・オイラー法を再帰計算として組み立てる

運動学的関係式、リンクごとのニュートン・オイラー方程式、リンク内部の力とモーメントのつり合いを組み合わせ、外向き計算と内向き計算にまとめます。

9.8-9.9

2自由度アームで両手法の一致を確認する

具体的な回転行列、重力、重心、慣性テンソル、境界条件を入れて計算し、ラグランジュ法で得た結果と同じ運動方程式になることを確認します。

この章の読み方

ラグランジュ法は「式の意味を見抜く方法」です。エネルギーから M, h, g がどう現れるかを理解しやすい一方、自由度が増えると式展開が重くなります。

ニュートン・オイラー法は「実装する方法」です。リンクごとの速度、加速度、力、モーメントを再帰的に渡すため、多自由度でも計算手順を保ちやすいです。

実務では、理論の検算にはラグランジュ法、リアルタイム計算や逆動力学の実装にはニュートン・オイラー法、という使い分けが自然です。

ラグランジュ関数 L = E_k - E_p
ラグランジュ方程式 d/dt(∂L/∂qdot_i) - ∂L/∂q_i = f_i
標準的な運動方程式 M(q) qdd + h(q, qdot) + g(q) = τ
運動エネルギーの一般形 E_k = 1/2 qdot^T M(q) qdot
ニュートン・オイラーの出力 τ_i = z_i^T n_i (回転関節), τ_i = z_i^T f_i (直動関節)

1. ラグランジュ法で何をしているのか

9.1では、2自由度平面アームを例に、各リンクの重心位置を座標で表し、それを時間微分して速度を得ます。並進運動エネルギーは重心速度から、回転運動エネルギーは各リンクの角速度と慣性モーメントから計算します。

  • リンク1の重心は θ1 によって動く。
  • リンク2の重心は θ1 と θ2 の合成角によって動く。
  • 運動エネルギーは並進分と回転分の和になる。
  • 位置エネルギーは重力方向の高さ、つまり重心の y 成分で決まる。

2. M(q), h(q,qdot), g(q) に分かれる意味

導出後の式は、加速度に比例する項、速度の積で現れる項、姿勢だけで決まる重力項に整理できます。これは単なる記法ではなく、制御とデバッグの分類軸です。

項 意味 実務での見方
M(q)qdd 加速に必要な慣性負荷 動き出しや急加速で効く
h(q,qdot) 遠心力・コリオリ力 高速動作で誤差や振れとして現れる
g(q) 自重を支える負荷 静止時の垂れや重力補償で効く

3. 9.2の重要性: 安定性に効く性質

9.2では、具体例を離れて一般的なロボットの性質を見ます。運動エネルギーを qdot^T M(q) qdot の形で書けるため、M(q) は対称で正定値という重要な性質を持ちます。

  • 正定値性は、動いている限り運動エネルギーが正であることを意味する。
  • 対称性は、慣性の相互作用が物理的に整合していることを示す。
  • S(q,qdot) の歪対称性は、後の重力補償制御や安定性証明で便利な形を作る。

4. ニュートン・オイラー法の全体像

9.3以降では、リンクごとの力学を使います。まず、リンク間の速度・加速度の関係を作り、次に各リンクの重心に働く慣性力と慣性モーメントを求め、最後に関節軸方向へ射影してモータが出すべき τ を取り出します。

  1. 運動学的関係式で、親リンクから子リンクへ速度・加速度を渡す。
  2. ニュートンの式で、重心加速度から力 f を求める。
  3. オイラーの式で、角加速度と角速度からモーメント n を求める。
  4. リンク内部のつり合いで、先端側の負荷を根元へ戻す。
  5. 関節軸 z との内積で、有効トルクまたは有効力を得る。

5. 外向き計算で見落としやすい外積項

回転関節では、角速度に z_i qdot_i を足すだけでなく、角加速度では親リンクの角速度と関節軸方向速度の外積が現れます。これは、回転している座標系上でベクトルを微分しているからです。

  • 角速度: 親の角速度に関節の相対回転を加える。
  • 角加速度: qdd_i だけでなく、軸の向きが変わる効果を加える。
  • 重心加速度: 原点加速度に接線加速度と向心加速度を加える。

6. 内向き計算で何を回収しているのか

内向き計算は、手先側から根元側へ「このリンクを支えるにはどれだけの力とモーメントが必要か」を足し戻す処理です。先端に外力がなければ初期値をゼロにできますが、接触や荷重がある場合はここに外力を入れます。

  • 子リンクから来る力を、自リンクの慣性力に加える。
  • 子リンクから来るモーメントに、力の作用点ずれによるモーメントも加える。
  • 最後に z 軸方向成分だけを τ として取り出す。

8. この章を実務で使う時の最短ルート

最初から一般式を丸暗記するより、2自由度例を使って「外向きで運動を作る」「内向きで負荷を戻す」「最後に軸へ射影する」という流れをコードに写すのが近道です。

  1. 静止状態で g(q) だけが出るか確認する。
  2. 低速動作で h(q,qdot) が小さいことを確認する。
  3. 加速度を入れて M(q)qdd の符号と大きさを見る。
  4. 先端外力を入れて、根元側トルクが増えるか確認する。
  5. ラグランジュ法の2自由度式と、ニュートン・オイラー法の結果が一致するか検算する。

式の読み方

運動方程式を「故障診断表」として読む

実務で大事なのは、式を眺めて「いま何が足りないのか」を切り分けられることです。

τ = M(q) q̈ + h(q, q̇) + g(q)
τ 各関節が出す一般化力。回転関節ならトルク、直動関節なら力。
M(q) q̈ 姿勢で変わる「動きにくさ」と、目標加速度が作る慣性負荷。
h(q, q̇) 遠心力・コリオリ力。速度が0なら消える、動いている時だけの負荷。
g(q) 自重を支えるための項。静止中でも必要なトルク。
症状 疑う項 実務で見るもの
速く動かすと軌道が膨らむ h(q, q̇) 速度2乗に効く遠心・コリオリの補償不足
腕を横に伸ばすと垂れる g(q) 重心位置、リンク質量、重力補償の符号
加速開始で大きく遅れる M(q) q̈ 慣性パラメータ、加速度指令、減速機比
実装目線の読み方 静止でずれるならまず g(q)。速度を上げると悪化するなら h(q, q̇)。加速の瞬間だけ重いなら M(q)q̈。式は、単なる完成形ではなくデバッグの索引です。
漸次アルゴリズム

ニュートン・オイラー法は、往復する計算パイプライン

ラグランジュ法が全体のエネルギーから式を作るのに対し、ニュートン・オイラー法はリンクごとの力学を隣へ渡します。多自由度でも式が爆発しにくいのが強みです。

外向き計算 根元 → 先端

  1. 親リンクの状態を受け取る

    ω, α, 原点加速度を、根元から順に渡す。

  2. 関節の相対運動を足す

    q̇ と q̈ を関節軸 z に沿って足す。軸自体が回るので外積項も入る。

  3. 重心加速度を求める

    原点加速度に、接線加速度 α×r と向心加速度 ω×(ω×r) を加える。

内向き計算 先端 → 根元

  1. リンク自身の慣性力を計算

    質量、重心加速度、慣性テンソルから f と n を作る。

  2. 子リンクの負荷を回収

    先端側にぶら下がるリンクの力とモーメントを合計する。

  3. 関節軸へ射影する

    回転関節は τ = zᵀn、直動関節は τ = zᵀf で駆動成分だけ取り出す。

Python実装

Pythonに落とす時の骨格

最初から完全なライブラリを目指すより、データ構造、外向き、内向き、射影の4つを分けると理解しやすくなります。

inverse_dynamics.py 概念スケルトン 
def inverse_dynamics(model, q, qd, qdd, gravity):
    # 1. 外向き計算: rootからtipへ速度・加速度を伝える
    states = []
    parent_w = zeros3()
    parent_alpha = zeros3()
    parent_acc = -gravity

    for i, link in enumerate(model.links):
        z = joint_axis_in_world(model, i, q)
        r = link.origin_from_parent
        s = link.com_from_origin

        w = parent_w + z * qd[i]
        alpha = parent_alpha + z * qdd[i] + cross(parent_w, z * qd[i])
        origin_acc = parent_acc + cross(parent_alpha, r) + cross(parent_w, cross(parent_w, r))
        com_acc = origin_acc + cross(alpha, s) + cross(w, cross(w, s))

        states.append((w, alpha, origin_acc, com_acc, z))
        parent_w, parent_alpha, parent_acc = w, alpha, origin_acc

    # 2. 内向き計算: tipからrootへ力・モーメントを回収する
    tau = zeros(model.dof)
    child_force = zeros3()
    child_moment = zeros3()

    for i in reversed(range(model.dof)):
        link = model.links[i]
        w, alpha, origin_acc, com_acc, z = states[i]

        f = link.mass * com_acc + child_force
        n = link.inertia @ alpha + cross(w, link.inertia @ w) + child_moment

        if link.joint_type == "revolute":
            tau[i] = dot(z, n)
        else:
            tau[i] = dot(z, f)

        child_force, child_moment = propagate_to_parent(f, n, link)

    return tau
座標系を混ぜない ベクトルがワールド座標かリンク座標かを関数名や型で明示する。
外積項を省略しない 回転座標系でベクトルを微分すると、向きの変化による項が出る。
最後は必ず射影 モータが出すのは軸方向成分だけ。全モーメントをそのまま使わない。
静止テストから始める q̇ = 0, q̈ = 0 なら、結果は重力補償トルクだけになる。
単位を固定する 角度はrad、長さはm、質量はkg、トルクはN mに統一する。
摩擦は別枠で扱う 基本式に入らない現実要素として、静止摩擦やバックラッシを切り分ける。
最終チェック

最後に確認クイズ

提示資料にある「理解度を見極めるための10の質問」を、採点できる三択クイズとして収録しています。採点後に各問の解説が開きます。

1. 角加速度の式で、単に q̈ᵢ を足すだけでなく ωᵢ₋₁ × (zᵢ q̇ᵢ) が現れる理由は？

この外積項は、回転している座標系から見た関節軸方向ベクトルの時間微分に由来します。大きさだけでなく「向きが変わる」ことも加速度を生みます。

2. 重心加速度の式に出てくる ω × (ω × r) は何を意味する？

二重の外積は、回転している点が中心方向へ向かう向心加速度の3次元ベクトル表現です。α × r は接線加速度として区別します。

3. τᵢ = zᵢᵀ nᵢ のように、関節軸ベクトル z との内積を取る理由は？

関節は構造的に動ける方向が決まっています。軸方向以外の成分は軸受けなどの反力として扱われます。

4. ニュートン・オイラー法で、加速度は根元から先端へ、力・モーメントは先端から根元へ計算する理由は？

速度・加速度は親リンクの運動を土台に決まり、力・モーメントは先端側の負荷を支えるため根元へ集まります。この因果の向きが往復計算になります。

5. 直動関節で τᵢ を求めるとき、モーメント n ではなく力 f を使う理由は？

回転関節の駆動量はトルク、直動関節の駆動量は力です。ただし運動方程式では、どちらも一般化力として τ で統一できます。

6. 慣性行列 M(q) が正定値かつ対称であることは何を保証している？

正定値性はエネルギーが正であること、対称性は物理的整合性を示します。制御の安定性証明やシミュレーション検算にも効きます。

7. 自由度が10以上ある複雑なロボットで、ラグランジュ法よりニュートン・オイラー法が選ばれやすい最大の理由は？

ラグランジュ法は自由度が増えるとシンボリックな式展開が重くなります。ニュートン・オイラー法はリレー形式で実装しやすいのが強みです。

8. 運動方程式の h(q, q̇) 項は、関節速度 q̇ が0のときどうなる？

遠心力やコリオリ力は速度に依存して発生します。静止状態では h(q, q̇) は消え、基本的には重力項が残ります。

9. 重力補償を実装してもロボットが完全に静止しない場合、基本的な運動方程式が考慮していない物理現象として考えやすいものは？

重心位置は動力学パラメータとして入りますが、摩擦やバックラッシは基本的な剛体運動方程式から外して扱われることが多いです。

10. インピーダンス制御でロボットの「見かけの質量」を変えるには、運動方程式のどの項を打ち消す考え方が必要？

インピーダンス制御では、ロボット本来の慣性をモデルやセンサで補償し、仮想的な慣性・粘性・剛性を感じさせる「動特性の書き換え」を行います。
